CRAVE CAMPUS — STUDY EDITION

FILES
- index.html: all five screens in one HTML document (Home, Login, Register, Forgot Password, Help).
- style.css: all visual styling for the five screens, formatted into readable rules and declarations.
- script.js: all front-end behaviour, including account-form validation, help interactions, food menus, search, cart and page navigation.
- Crave-Website-Explained.pdf: a beginner-friendly guide to the website and its code.

HOW TO RUN
1. Keep index.html, style.css and script.js in the same folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.

IMPORTANT
This is a front-end project. Login, registration, password reset email delivery, support-ticket delivery and real payment/order processing require a secure backend. The current checkout is explicitly a demo.

CODE PRESERVATION
The HTML/CSS/JavaScript instructions and values have been retained. Formatting whitespace and explanatory comments were added to make the source easier to study.
